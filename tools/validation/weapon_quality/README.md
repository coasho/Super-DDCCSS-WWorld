applicable components, functions, independently checked methods, integration and
reproducible delivery. Actual equipment accuracy is a separate uncertainty
ledger. Missing execution, failed tests and unexercised models cannot be waived
as uncalibrated. The final admission requires no unclosed engineering gate.
