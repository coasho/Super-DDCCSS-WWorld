three-domain migration ([roadmap](../roadmap.md)). They were archived here from `docs/superpowers` by ARCH-09
(2026-10-17), register rows D11-D13. Each is kept as written: its dates, decisions, achieved evidence and remaining
work are the record of that pass.

in [validation](../../validation/) and the documents in the [architecture index](../../README.md) supersede them where
