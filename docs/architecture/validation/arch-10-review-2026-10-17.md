## 1. HC-38: SYSTEM includes bypass owned-path checks (P2)

`tools/architecture/configured.py:166` accepts an include marked `isSystem` before checking whether its source
directory or include view belongs to the module's dependency closure. SYSTEM controls compiler diagnostics; it
does not grant dependency ownership.

Using the existing synthetic fixture, `core` including `src/sim` or `build/include-views/fsim_sim` ordinarily exits
1 with `include-outside-closure`. Marking either identical path SYSTEM instead exits 0. The valid control also
exits 0. These are configured-reply fixtures; no production source or CMake file was changed.

Closure: validate owned source paths and include views before applying system/external include allowances.
Preserve valid toolchain/vendor cases and add both SYSTEM refusal regressions.

## 6. HC-43: minimum CMake support and mandatory gate requirements conflict (P2)

Root `CMakeLists.txt:1` and `docs/development.md:14` retain CMake 3.25 support. The newly mandatory configured gate
requires codemodel 2.9 or later (`configured.py:37,56`), while CMake 3.25's documented model is 2.4. The existing
fixture with version 2.4 exits 2, even when its graph is otherwise valid. The older-CMake query-file fallback
does not provide the newer direct-link fields.

Primary support evidence: [CMake 3.25 File API codemodel documentation](https://cmake.org/cmake/help/v3.25/manual/cmake-file-api.7.html#codemodel-version-2).
The installed 4.4.3 documentation also identifies the direct-link fields as codemodel 2.9 additions. No older
toolchain was installed or tried. This is a compatibility-contract finding; the current 4.4.3 builds pass.

Closure: reconcile native-build support and architecture-check tooling explicitly. Preserve the declared supported
baseline through a validated alternative where required, or obtain and document an explicit compatibility decision
for any narrower checking requirement. Add version/capability coverage and a clear actionable diagnostic; do not
silently waive a required gate, call pending coverage passed, or raise the project's minimum incidentally.
