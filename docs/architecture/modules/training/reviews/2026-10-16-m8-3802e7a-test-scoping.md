tools/ma_contract/baseline.py:789 accepts any named-tuple field-list extension whose prefix matches. test_baseline.py:86 explicitly admits it. Adding even a defaulted third field to StrikeReport(activity, status) breaks an existing two-value unpack; a nondefaulted addition also breaks construction. baseline.py:750 also treats any equals sign in an appended parameter's text as a default. The valid signature `(a, b=1, *, c: '=')` is admitted over `(a, b=1)`, but an old call with only `a` raises TypeError because c is required. Determine actual parameter kinds/defaults rather than searching for an arbitrary equals sign, or reject additions that cannot be classified safely.
