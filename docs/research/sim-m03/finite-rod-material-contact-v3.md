# Finite-rod material-contact episodes V3

This is a versioned, lumped game constitutive law, not a calibrated distributed rod/material penetration model. A connected finite element pays the unchanged whole-element THOR plate response once at the first local facet/normal of a connected homogeneous-sheet contact episode. Stable existing source order chooses simultaneous ties. Subsequent shared-edge transitions in that same contact set do not charge the entire mass and presented area again. A different authored THOR thickness starts a distinct response domain.

The exact flat ownership-partition invariance follows from equal physical skin union, material, projectile and path; it is not a claim that first-normal whole-element THOR is exact for a curved or creased shell. Curved continuation is explicitly a surrogate. No external publication is claimed to validate that surrogate. The existing plate law remains a steel-fragment/2024-T3 aluminium game approximation, not model-specific hardware calibration.

Private active facet seeds are distinct from historical V1 crossedFaces. Each feasible facet contact retains the provenance of its entry/exit clip constraints. Shared physical-coordinate edges, matching victim/generation, retained immutable geometry and identical plate thickness are required. Mere time overlap, global shell connectivity, panel names, or normal grouping do not establish a branch. An initial-time slice also retains all edge bounds, so a finite spatial contact segment is joined at its actual material coordinate rather than only its lexicographically first point.

The original collision roots, normal selection, physical masks and numerical coordinates remain authoritative. Provenance is admitted only if the repeated boundary observer returns exactly those coordinates. Independently rounded exit/entry roots may be joined only after outward interval arithmetic certifies the unique affine shared-edge event inside the actual time, rod-coordinate and finite-edge domains. Collinear, singular or uncertain interval cases do not authorize that gap bridge; no distance, timing or angle epsilon is added.

A paid facet is active only while its represented feasible domain reaches the current boundary. A positive absence expires it before candidate suppression. A freshly observed native contact is an explicit same-epoch boundary witness and can survive a reconstruction rounding discrepancy only with the identical represented target pose; positive flight clears freshness. Changed held attitudes restart the represented contact domain, rather than inventing an unprovided rotation sweep. The ordinary captured moving-origin intervals remain authoritative. This limits cross-attitude fidelity and is not a claim of continuous rotational CCD.

Private V3 history uses bit-exact ordered source snapshots (including signed zero and ordinal labels) and exact continuation age. Invalid assessment returns no partial result and publishes no history. V1 wrappers retain their signatures and use transient same-call state while preserving incoming historical face exclusions; they cannot establish a cross-call active episode. World continuations explicitly own V3 state and stage it with each field. No public SDK value layout or provider vtable changes.

Native separation is the sole authority for ownership rebind. The map records old/new identity and generation, owning old/new immutable geometry, and exact transferred panel indices; detachedState preserves original triangle indices while translating the actual geometry. Name aliases and unrelated victims cannot transfer state. Staged maps are applied after structural births before continuation publication; failed preparation retains old field/history/queues.

The new native controls cover the unchanged ownership RED, call splits before/at/after a seam, exact shared-edge initial contact, q-separated opposing walls, unequal plate thickness, forced captured-motion absence and reentry, source-bit and invalid-input rollback, changed generation, and the actual native detachedState material mapping. The detachedState test is a material-handoff unit witness, not a complete World flight-model birth acceptance. The original native World contact/separation gates and current full chains remain required integration checks.

Zero-COM-speed material contacts retain an explicitly unpaid active marker only to prevent a zero-time repeat of the same facet. Such markers cannot authorize homogeneous-branch debit coalescing. A later positive-gap episode re-arms normally. This preserves the existing no-work zero-COM response without creating a false paid history.

World ownership maps also apply to effects already published at the same boundary: their field/time remains unchanged while the material owner of a retained active seed is updated. Queued handoff maps are cleared only after all corresponding staged history has committed.

The external V3 history pose is always canonical ECEF. Liquid floating-origin recursion translates staged active poses together with the field/recipients, then restores every retained/new active pose only on valid return. The Earth-scale consecutive-call control isolates this real entrypoint with an explicitly empty liquid population; it does not claim wet-material validation.

Existing V2 custom providers retain zero=unknown and duplicate ordinal labels. Within one World-owned source, the exact ordered continuation population owns per-index history; diagnostic labels do not grant runtime identity authority. The actual custom-sidecar control emits two unknown-zero labels, with one rod intersecting and the other missing, then verifies independent history across two real V3 assessments. It is a native virtual-capability unit, not a claim of installed custom-registry/World campaign acceptance. Authored production-model positive ordinal/identity coverage gates remain separate and unchanged.

If boundary provenance cannot be proved identical to the native polygon, that facet retains the original visited-face exclusion path. It does not enter active-branch suppression/reentry processing or repeat a zero-time debit. This is a conservative compatibility fallback, not acceptance of an unproved material-domain join.

The first feasible time can contain a finite interval of rod material coordinates even when it is strictly positive. Provenance therefore retains all physical-edge bounds on the entire earliest-time slice, not only the lexicographic first point or an initial-time slice. This makes a coplanar triangle diagonal independent of the small positive native reconstruction time, without tolerance or merged-face-only suppression.
